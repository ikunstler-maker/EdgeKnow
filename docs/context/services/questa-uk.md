# Questa — опитування й форми

> **Картка сервісу.** Читати разом із `docs/context/00-overview-uk.md` (загальний опис). **Стан на:** 2027-01-14. Джерело правди — `docs/decisions.md` і код.

## 1. Призначення

Форми й опитування: для команди й для людей без акаунта. Відповіді одразу потрапляють у підключену таблицю.

- **Стан:** ✅ працює.
- **Адреси:** `/w/<id>/surveys`, `/w/<id>/surveys/<опитування>`; відкрита форма — `/f/<workspace>/<ключ>`.

## 2. Що вже зроблено

### Форма
- Розділи з питаннями: короткий і довгий текст, один чи кілька варіантів, список, шкала, зірки, дата, **файл** (до 5 файлів по 4 МБ).
- «Обов'язкове»; переходи між розділами, зокрема залежно від вибраного варіанта.
- База сама перевіряє відповідь за формою й зберігає лише відповіді на пройденому шляху.

### Налаштування
- **Анонімне** (ім'я не записується зовсім; після першої відповіді не змінюється).
- Одна відповідь від людини; можна змінити свою відповідь (лише неанонімне).
- Приймати відповіді; закрити після дати або кількості відповідей.

### Відповіді
- Бачать лише редактори опитування (крім гостей), його власник, власник і адміністратори workspace.
- Підсумки з діаграмою для кожного питання, середнє, таблиця всіх відповідей.

### Посилання для будь-кого
- Вмикається в налаштуваннях; «Нове посилання» одразу вимикає старе.
- Усе проходить лише через сервер; анонімна роль бази не має жодного доступу.
- Обмеження: до 5 відповідей з пристрою за 10 хвилин, до 300 на годину на опитування. Пристрій — односторонній хеш; адреса не зберігається.
- Перевірка «я не робот» вмикається, коли задано ключі в налаштуваннях хостингу.
- Файл через посилання можна додати лише після входу.

### Спільне
- Перелік, кошик, доступ, колекції.

## 4. Дані

| Таблиця | Що зберігає |
|---|---|
| `service_objects` (service `surveys`) | форма |
| `survey_settings` | налаштування, ключ відкритого посилання, підключена таблиця |
| `survey_responses`, `survey_respondents` | відповіді й хто відповів |
| `survey_public_hits` | лічильники обмежень для відкритого посилання |
| `object_files` | файли відповідей |

Таблиці відповідей доступні лише через функції бази.

## 7. Важливі рішення

- Анонімність справжня: ім'я не зберігається навіть для власника.
- Відкрита форма — єдине місце продукту, куди пише людина без акаунта; тому тільки через сервер і з обмеженнями.
- Завантажені, але не надіслані файли прибираються через добу.

## 8. Відомі прогалини й відкриті питання

- Підтвердити, що перевірка «я не робот» показується на відкритих формах після додавання ключів.
- Попередження про персональні дані у відкритих формах — узгодити з політикою конфіденційності перед запуском.
