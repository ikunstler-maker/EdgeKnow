# Bordy — дошки й дизайн

> **Картка сервісу.** Читати разом із `docs/context/00-overview-uk.md` (загальний опис). **Стан на:** 2027-01-14. Джерело правди — `docs/decisions.md` і код.

## 1. Призначення

Простір для спільного мислення й макетів. У сервісі два види файлів:
- **«Дошка для ідей»** — безмежне полотно зі стікерами, фігурами, шаблонами, голосуванням і таймером.
- **«Дизайн»** — редактор інтерфейсів: рамки-екрани, шари, авто-розкладка, прототипи.

- **Стан:** ✅ працює (обидва види).
- **Адреси:** `/w/<id>/boards`, `/w/<id>/boards/<дошка>`.

## 2. Що вже зроблено

### Дошка для ідей
- Полотно: фігури, стрілки, текст, олівець, рамки-розділи, масштаб, збереження як PNG/SVG.
- Стікери чотирьох кольорів.
- **Шаблони:** ретроспектива, мозковий штурм, шлях клієнта, SWOT, канбан, сітка.
- **Голосування:** N голосів на кожного, підсумок за кількістю голосів. Голосують усі, хто може коментувати.
- **Спільний таймер** (1–15 хвилин).
- **Зображення:** стискаються й зберігаються в сховищі workspace; у дошці — лише посилання.
- Задача зі стікера.

### Дизайн
- Сторінки файлу, безмежне полотно.
- Рамки з розмірами пристроїв і обрізанням; вкладеність; дерево шарів із пошуком і перетягуванням.
- Авто-розкладка (рядок, стовпець, з перенесенням; відступи, поля, вирівнювання); обмеження при зміні розміру рамки.
- Перо (криві) і редагування точок; кілька заливок і обведень; імпорт SVG.
- **Прототипи:** переходи між рамками, програвач в окремій вкладці.
- Задача з тексту; копіювання стилю; експорт PNG / SVG / PDF.

### Спільне для обох
- Перелік, кошик, доступ (власник, адміністратори, увесь workspace, люди, підрозділи; гості — лише якщо поділилися).
- Колекції в лівій панелі.

## 7. Важливі рішення

- Один власний рушій полотна для «Дизайну» й презентацій; дошка для ідей працює на окремій бібліотеці полотна з відкритою ліцензією.
- «Дизайн» — новий вид файлу в тому самому сервісі, а не окремий сервіс.
- Темне оформлення редактора «Дизайну» — лише для цих редакторів; світла тема теж є.
- Назв сторонніх продуктів у репозиторії немає.

## 8. Відомі прогалини й відкриті питання

- Спільне редагування потребує вибору технології й оцінки вартості.
- Ліміт Free «кількість дощок» — відкрите питання тарифів.
