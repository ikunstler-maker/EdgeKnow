# Wika — вікі

> **Картка сервісу.** Читати разом із `docs/context/00-overview-uk.md` (загальний опис). **Стан на:** 2027-01-14. Джерело правди — `docs/decisions.md` і код.

## 1. Призначення

База знань команди: дерево сторінок із редактором блоків, коментарями й доступами. Wika — **центр екосистеми**: у її сторінки вставляються об'єкти всіх інших сервісів, і з неї починався продукт.

- **Стан:** ✅ працює.
- **Адреси:** `/w/<id>` (головна workspace), `/w/<id>/p/<сторінка>`.

## 2. Що вже зроблено

### Сторінки й дерево
- Дерево сторінок із підсторінками, перетягування, переміщення, іконка, обкладинка, автор і дати.
- **Миттєве створення:** сторінка з'являється одразу, база записує у фоні; якщо не вдалося — «Не збережено» з повтором.
- **Кошик:** видалена сторінка зберігається 30 днів, потім видаляється назавжди.
- Лічильник сторінки (символи, слова, час читання) і особиста статистика в профілі.

### Редактор
- Блоки: текст, заголовки H1–H3, списки, чек-листи, таблиця з кольорами клітинок, код, цитата, виноска (callout), зображення (завантаження чи посилання), YouTube, картка посилання, навігація, зміст.
- **Галерея:** зображення, YouTube, аудіо; чотири вигляди.
- **Діаграма** (нодова схема) прямо в сторінці.
- **Чіпи:** сторінка, людина, задача; чіп-перемикач (статус, версія, пріоритет).
- **Текст видно одразу:** сервер малює збережений текст сторінки, доки завантажується код редактора.
- Автозбереження. **Конфлікт редагування:** якщо хтось зберіг раніше — вибір «відкрити їхню версію» або «залишити мою».
- Вміст — документ у форматі редактора (JSON), до 1 МБ тексту на сторінку.

### Коментарі й згадки
- Коментарі до виділеного тексту (позначка рухається разом із текстом), гілки, згадки через «@».
- Перемикач «Зміст / Коментарі» збоку.

### Доступи
- Ролі сторінки: власник / редагування / коментування / перегляд.
- Підсторінка успадковує доступ батьківської; «Обмежити доступ» дає їй власний список.
- Доступ можна дати всьому workspace, людині, підрозділу; гостю — лише особисто.

### Особливі можливості
- **Підтвердження ознайомлення:** власник сторінки вмикає кнопку «Ознайомився(-лась)» / «Приймаю умови» / «Погоджуюсь»; сторінка заморожується; статистика, хто підтвердив; нова редакція вимагає нового підтвердження.
- **Сторінка із зовнішнього джерела:** адміністратор вказує адресу з Markdown — сервер наповнює й оновлює сторінку.
- **Резервні копії сторінок** на Google Диск: щодня й кнопкою, у JSON і Markdown.
- **Чернетки:** нова сторінка — чернетка, її бачать лише автор, особисто запрошені й власник workspace (фільтр поверх звичайних прав; адміністратори й підрозділи її не відкривають); усе всередині чернетки теж приховане; запрошення відкриває лише ту чернетку, а вікно «Поділитися» пропонує надати такий самий доступ і до вкладених сторінок. «Опублікувати» (автор або редактор), за бажанням разом із вкладеними сторінками. Правило — у `page_role_of` (сторінки, дерево, пошук, коментарі, файли, сповіщення, чипи) і `my_page_tree`; на чернетці не вмикається підтвердження ознайомлення; чернетки не потрапляють у резервну копію на Google Диск. Наявні сторінки опубліковано датою створення.
- **Історія версій** (лише автор і редактори): одна версія на сеанс редагування (одна людина, перерви менше 10 хвилин), а також при публікації, новій редакції з підтвердженням і поверненні; перегляд з підсвіткою змінених абзаців; «Повернути цю версію» (текст до повернення лишається в історії; не на замороженій сторінці й не в кошику; коментарі, чий текст зник, позначаються, а не видаляються). Зберігається 7 днів, остання версія — завжди. Таблиця `page_versions`, тригер на сторінках, `restore_page_version`, `prune_all_page_versions`.
- **Меню «Експорт»** поруч із «Поділитися»: скопіювати посилання на сторінку (відкриється лише тим, хто має доступ); PDF і Markdown (Free); JSON, CSV, DOCX, HTML видно неактивними зі значком PRO. PDF: окремий вигляд сторінки для друку (`/p/<id>/print`, редактор лише для читання, світла тема) чекає на вставки й зображення і відкриває вікно друку браузера («Зберегти як PDF») — сервер нічого не рахує. Markdown: збирається в браузері з однієї дії сервера, яка читає вставки з правами самої людини; таблиці стають таблицями Markdown (до 500 рядків на аркуш), задачі — списком із позначками, інші вставки — рядком із посиланням, чіпи — посиланнями; закрите — «🔒 Немає доступу» без назви; коментарі не потрапляють. Завантажені зображення й аудіо йдуть в архів .zip поруч із .md (`files/`); зображення з інших сайтів лишаються посиланнями.

### Пошук
- Назви й текст сторінок, ноди схем, картки посилань; за типом вмісту (заголовки, зображення, код, чек-листи тощо).
- Область: весь workspace або сторінка з підсторінками. Лише те, що людина може відкрити.

## 4. Дані

| Таблиця | Що зберігає |
|---|---|
| `pages` | сторінки: дерево, назва, вміст, версія, кошик, `published_at` (порожньо — чернетка) |
| `page_access`, `page_group_access` | доступ людей і підрозділів |
| `comment_threads`, `comments` | коментарі |
| `page_mentions` | згадки |
| `page_contributions` | хто що змінював (для статистики) |
| `page_backups` | стан резервних копій |
| `page_versions` | історія сторінок (версії за сеансами редагування) |
| `page_acks`, `page_ack_revisions` | підтвердження ознайомлення |
| `external_sources` | зовнішні джерела сторінок |
| `attachments` | файли сторінок |

- Збереження вмісту — через адресу `/api/pages/<id>/content` і функцію бази з перевіркою версії.
- Дерево сторінок для лівої панелі читається функцією `my_page_tree` (ролі всіх сторінок за один прохід; тест `stage51_fast_reads` порівнює її з читанням таблиці рядок у рядок). Зміна правил доступу до сторінок має оновити й цю функцію.
- Таблиці є і в центральній базі, і в базі команди.

## 5. Зв'язки з іншими сервісами

| Сервіс | Зв'язок |
|---|---|
| **Rukh** (задачі) | чіп задачі й список задач на сторінці; «задача з виділеного тексту»; задача посилається на сторінки |
| **Bordy** (дошки) | вставка дошки |
| **Nodo** (карти) | вставка карти чи схеми |
| **Sota** (таблиці) | вставка таблиці або діаграми; клітинки можна змінювати прямо на сторінці |
| **Questa** (опитування) | вставка форми або підсумків |
| **Kadry** (презентації) | сторінка вікі вставляється у слайд карткою |
| **Ядро** | пошук, сповіщення про згадки, аналітика, сховище файлів. Колекцій у вікі немає: їх замінює дерево сторінок |
| **Профіль** | блок «ВішЛіст»: жива картка ВішЛіста колеги з перевіркою доступу |
| **Vault** | блок «Файл із Vault» (`vaultFile`): жива картка файлу з перевіркою доступу; без доступу — «Файл недоступний» (VAULT-3) |

**Правило вставок:** у сторінці зберігається лише ID об'єкта. Права перевіряються щоразу за об'єктом, а не за сторінкою.

## 7. Важливі рішення

- Заголовки лише H1–H3.
- Вбудовування чужих сайтів заборонене; виняток — YouTube через адресу без відстеження.
- Пошук — вбудований у базу, без української морфології (збіг за початком слова), без доплат.
- Коментатор не змінює текст: позначку коментаря ставить сервер і перевіряє, що змінилась лише вона.
- Заморожену сторінку (з підтвердженням) не змінює ніхто, доки власник не почне нову редакцію.

## 8. Відомі прогалини й відкриті питання

- Формати експорту й межа Free/PRO залежать від реалізації тарифів.

## Екран (оновлення 2026-11-11)
- Сторінка має одну шапку вгорі (липку): ліворуч — джерело тексту (якщо сторінка наповнюється з адреси), праворуч — «Підтвердження», «Історія», «Експорт», «Поділитися». На сторінці із зовнішнього джерела перший заголовок, що повторює назву сторінки, не показується вдруге. Зміст праворуч — тонка липка рейка без системної смуги прокрутки. Значки в редакторі, виносках, чипах і блоках — намальовані; емодзі лишається тільки як значок сторінки, який вибрала людина.
