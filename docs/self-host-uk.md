# Власна копія EdgeKnow для вашої команди

> **Чернетка.** Так інструкція виглядатиме після доопрацювань з «Плану робіт після пілоту» (SPEC). Зараз ці кроки ще не працюють.

Ваша команда отримає власну вікі, яка не залежить від нікого: сайт, база даних і файли належать вам. Усі сервіси безкоштовні, банківська картка не потрібна.

**Час:** 30–40 хвилин. **Знання програмування:** не потрібні. Ви будете лише натискати кнопки й копіювати значення з одного вікна в інше.

**Знадобиться:**
- Google-акаунт власника команди (бажано робочий);
- 4 вкладки браузера.

---

## Крок 1. Акаунти (5 хв)

Створіть безкоштовні акаунти, якщо їх ще немає. Скрізь входьте через **«Continue with GitHub»**:

1. **GitHub** — github.com → Sign up.
2. **Vercel** — vercel.com → Sign up → тариф **Hobby**.
3. **Supabase** — supabase.com → Start your project.

## Крок 2. Кнопка «Deploy» (10 хв)

1. Натисніть кнопку **[▲ Deploy to Vercel]** на сторінці проєкту на GitHub.
2. Vercel запропонує:
   - **Create Git Repository** — залиште назву як є → **Create**.
   - **Supabase** — натисніть **Add**, потім **Create new project**. Регіон оберіть найближчий до команди, наприклад Frankfurt.
3. Натисніть **Deploy** і зачекайте 3–5 хвилин. Vercel сам:
   - створить базу даних;
   - запише всі ключі туди, де вони мають бути;
   - збере сайт.
4. Коли з'явиться конфетті, натисніть **Continue to Dashboard** і скопіюйте адресу сайту, наприклад `https://our-wiki.vercel.app`.

## Крок 3. Вхід через Google (15 хв)

Це найдовший крок. Він потрібен, щоб люди входили своїм Google-акаунтом, а сервіс міг зберігати файли на ваш Google Drive.

1. Відкрийте **console.cloud.google.com** → **Create project** → назва, наприклад, «Our wiki».
2. **APIs & Services → Library**: знайдіть **Google Drive API** → **Enable**.
3. **Google Auth Platform → Get started**:
   - назва застосунку — назва вашої вікі;
   - пошта підтримки — ваша;
   - **Audience**:
     - **Internal**, якщо у вашої компанії Google Workspace. Тоді входять лише колеги;
     - **External**, якщо входити мають будь-які Google-акаунти. Після створення натисніть **Publish app**.
4. **Clients → Create client → Web application**. В обидва поля вставте адреси, які показує сторінка налаштування вашого сайту (див. крок 4):
   - **Authorized JavaScript origins** — адреса сайту;
   - **Authorized redirect URIs** — дві адреси.
5. Скопіюйте **Client ID** і **Client secret**.

## Крок 4. Майстер налаштування на вашому сайті (5 хв)

1. Відкрийте адресу сайту з кроку 2. З'явиться сторінка **«Перше налаштування»**.
2. На ній:
   - адреси для кроку 3.4 — з кнопкою «Скопіювати»;
   - поля для **Client ID** і **Client secret** з кроку 3.5. Вставте їх → **Зберегти**.
3. Майстер сам перевірить, що все працює, і покаже зелені галочки ✅.
4. Натисніть **Увійти через Google**. Ви станете власником вікі.
5. Майстер запропонує:
   - назвати workspace;
   - підключити Google Drive для файлів і резервних копій;
   - додати домен або запросити колег.

**Готово!** Далі все налаштовується в самій вікі: **⚙️ Налаштування workspace**.

---

## Оновлення

Коли виходить нова версія, на вашому сайті з'являється повідомлення «Доступне оновлення». Натисніть **Оновити**. Сайт оновиться сам за кілька хвилин, а база даних — разом із ним.

## Що безкоштовно і де межі

| Сервіс | Що там зберігається | Безкоштовний ліміт (орієнтовно) |
|---|---|---|
| Vercel Hobby | сам сайт | приблизно 100 ГБ трафіку на місяць — це десятки тисяч переглядів сторінок |
| Supabase Free | тексти, коментарі, доступи | 500 МБ — це тисячі сторінок |
| Ваш Google Drive | зображення, резервні копії | місце на вашому Drive |

- **Supabase:** якщо вікі не відкривали 7 днів, база «засинає». Розбудити її можна кнопкою **Restore** у панелі Supabase.
- **Vercel Hobby:** дозволене лише некомерційне використання. Для комерційного використання потрібен Vercel Pro.

## Якщо щось не так

Майстер з кроку 4 пише, що саме не працює і що з цим зробити. Повторно відкрити його можна за адресою `https://ваш-сайт/setup` (тільки для власника).

## Для розробки: що треба зробити, щоб інструкція стала такою

- **Кнопка «Deploy to Vercel»** з інтеграцією Supabase: Vercel сам створює базу й передає ключі. Застосунок має приймати назви змінних, які дає інтеграція.
- **Міграції бази** запускаються автоматично під час кожної збірки на Vercel, без GitHub Secrets.
- **Внутрішні секрети** (шифрування доступу до Drive, нічні задачі) виводяться із секретного ключа Supabase, тому вводити їх окремо не треба.
- **Майстер `/setup`:**
  - показує адреси для Google;
  - зберігає Client ID і secret у налаштування входу Supabase та в сам сервіс;
  - вмикає перевірку нових користувачів;
  - перевіряє все разом і робить першого, хто увійшов, власником.
- **Повідомлення «Доступне оновлення»** та оновлення копії з GitHub в один клік.
- **Перевірити наживо:**
  - чи потрібна перевірка Google для типу External з доступом лише до власних файлів (`drive.file`);
  - точні ліміти безкоштовних тарифів.
